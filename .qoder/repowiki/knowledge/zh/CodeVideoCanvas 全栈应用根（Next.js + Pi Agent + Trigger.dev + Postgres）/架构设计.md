仓库采用 Next.js App Router 作为统一入口：`src/app/` 下 `(app)` 路由组承载画布、项目、设置等页面，`api/` 暴露 REST 端点；业务逻辑按领域拆分到 `src/features/`（ai、artifacts、audio、canvas、director、navigation、render），基础设施能力集中在 `src/lib/`（config、db、determinism、gsap、hooks、layout、motion、queue、storage、stream）。数据层使用 Drizzle ORM + SQLite（迁移期）/Postgres（v3 目标），数据库配置在 `drizzle.config.ts`。异步编排由 Trigger.dev 的七个固定 task（cvc.pipeline.run / cvc.project.plan / cvc.shot.generate / cvc.shot.media / cvc.shot.render / cvc.shot.qa / cvc.project.compose）承担，Pi Agent 是唯一的 AI 运行时，模型选择收敛于 `ModelPolicy`。渲染管线遵循 `ShotSourcePackageV1 → video-compiler → CvcCompositionBundleV1 → RenderableBundleDescriptorV1 → HyperFrames` 的单向流，禁止反向依赖。UI 组件体系源自 Pencil，通过 `/playbook` 登记，`src/components/ui` 提供可复用原语，`src/app/(app)/layout.tsx` 挂载一次 `AppShell`。依赖方向严格限定为 `app + trigger → application services → domain/contracts → ports ← infrastructure adapters`，禁止跨域 deep import schema/repository/infrastructure。
