- 每个 feature/package 仅通过 index.ts 或包根导出公开能力，跨域禁止 deep import 对方的 repository、schema、infrastructure 或私有文件。
- page.tsx 目标 ≤200 行、硬上限 300；一般生产文件 ≤250 行、硬上限 350；schema/repository 硬上限 400；单函数 ≤50 行，超限必须真实拆分而非 re-export 包装。
- 默认 Server Component，'use client' 尽量下沉到叶子组件；Next.js 使用 proxy.ts 而非 middleware.ts，异步 params/searchParams/cookies/headers 必须 await。
- 用户可见状态必须追溯到 Snapshot、artifact 或 API，未实现能力显示 empty/disabled/placeholder，禁止固定假值伪装成功。
- 视频渲染代码禁止 requestAnimationFrame、GSAP ticker/play、Date.now/performance.now、unseeded Math.random、setTimeout/setInterval、网络请求、CSS animation/transition 及输入依赖状态。
- Pi Agent 调用仅限 pi-structured-runner.ts 的生产实现导入，所有 AI/LLM 模型选择收敛于 ModelPolicy.resolve(AiTaskKind, workspaceSettings)，TTS/ASR 使用独立的 MediaProviderPolicy。
- Trigger.dev task 薄壳只负责 parse payload、创建 context、调用 service、检查 Result、映射 output，业务状态机不放在 task 中。
- 新视觉组件严格按顺序：Pencil reusable symbol → 可复用组件与 demo → /playbook 登记 → 页面通过公共导出复用，/playbook 是唯一组件登记与展示路由。
