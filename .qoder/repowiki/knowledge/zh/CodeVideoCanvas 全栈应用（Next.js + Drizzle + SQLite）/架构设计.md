采用 Next.js App Router 全栈架构：`src/app/(app)` 为带侧边栏壳的应用路由组，`src/app/api/*` 暴露 REST API；`src/features/*` 按业务域划分（director 导演流水线、render 渲染与缩略图、canvas 画布数据、audio 音频、ai AI 适配、navigation 导航壳），每个 feature 通过 `index.ts` 统一导出类型与函数；`src/lib/*` 存放跨领域共享库（db、queue、stream、storage、gsap、motion、layout、workflow 等）。数据库层使用 Drizzle ORM + better-sqlite3，schema 位于 `src/lib/db/schema.ts`，迁移输出到 `src/lib/db/migrations`。队列系统通过 `instrumentation.ts` 在 Node 运行时初始化，`serverExternalPackages` 将 better-sqlite3 和 ffmpeg-static 标记为外部依赖以支持原生二进制。测试使用 Vitest，E2E 使用 Playwright，产物暂存于 `.data/` 和 `.playwright-cli/`。
