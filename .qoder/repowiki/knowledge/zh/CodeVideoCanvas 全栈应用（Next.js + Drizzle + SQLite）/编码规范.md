- 每个 features 模块通过 index.ts 集中 re-export 类型与函数，对外只暴露稳定接口，内部实现分散在多个文件中。
- 所有用户输入与配置均使用 Zod schema 进行校验，schema 定义与解析逻辑成对出现（如 schemas.ts + actions.ts）。
- API 路由采用 Next.js Route Handlers（route.ts），每个路由文件配套同名的 *.test.ts 单元测试。
- 组件文件遵循 `<name>.tsx` + `<name>.demo.tsx` 配对模式，便于 Storybook 或本地预览。
- 工具函数集中在 `src/lib/utils.ts`，如 cn() 用于合并 Tailwind className，避免在各组件中重复实现。
- 常量与枚举使用 as const 声明并派生 TypeScript 联合类型，保证类型安全（如 PIPELINE_STAGES、FRAME_THUMBNAIL_KIND）。
