单仓 Next.js App Router 全栈应用，按领域划分 `src/features/{canvas,director,render,ai,audio,navigation}` 业务层，`src/lib/*` 提供跨领域基础设施（SQLite/Drizzle、本地存储、队列、GSAP 桥接、确定性校验），`src/app/api` 暴露 REST 路由供前端调用。

- 渲染核心：`features/render/renderer.ts` 的 `HyperframesRenderer` 实现「guard → cache → capture → encode → commit」流水线，依赖注入 `StorageAdapter`、`lookupCache/writeCache`、`captureSequence`（Playwright/Chromium 逐帧 seek）、`encode`（ffmpeg-static），输出键由 html 内容+frames+seed 的 sha256 决定，支持定向重渲。
- Director 编排：`features/director/pipeline.ts` 声明 `PIPELINE_STAGES` 与 `STAGE_META`，通过 `PiSession` + `stage-runner` 驱动 ingest/fabricate/assemble/finalize 阶段，产物落盘到 `docs/video-director` 下的 productions/schemas/prompts 等目录。
- 持久化：`better-sqlite3` + `drizzle-orm`，迁移脚本位于 `scripts/setup/db-migrate.ts`；`next.config.ts` 将 `better-sqlite3`、`ffmpeg-static` 加入 `serverExternalPackages` 以绕过 Turbopack 重写。
- 前端：`src/app/(app)/canvas` 为 React Flow 主画布页面，`src/components/ui` 为 SSOT 组件库，`src/app/playbook` 注册演示页作为活文档。
- 测试：Vitest 单测与 Playwright E2E 并存，`tmp/u18-e2e` 存放端到端产物与日志。
