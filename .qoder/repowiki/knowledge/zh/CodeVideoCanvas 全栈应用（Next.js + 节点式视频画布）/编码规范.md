- 每个 features 子模块遵循统一文件组织：`types.ts` 定义接口、`schemas.ts` 放 Zod schema、`*.test.ts` 紧邻源码、可选 `service.ts` 封装外部依赖。
- 服务端能力通过依赖注入接口暴露（如 `StorageAdapter`、`RendererDependencies`），默认值在模块内构造，便于测试时替换 mock。
- 所有可复现的输出都通过内容哈希（sha256）做缓存键，避免时间戳或随机数污染结果。
- UI 组件采用「SSOT + demo」模式：`src/components/ui/*.tsx` 定义组件，同目录配 `*.demo.tsx`，并在 `src/app/playbook/registry.ts` 登记以便 `/playbook` 画廊展示。
- 颜色、阴影、圆角等视觉属性一律引用 Design Token，禁止硬编码 hex 值；图标统一使用 `lucide-react` 白名单，禁用 emoji。
