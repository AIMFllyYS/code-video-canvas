采用 Next.js App Router 单仓架构：`src/app/` 定义路由（`(app)` 路由组挂载 `AppShell` 常驻侧栏，`api/` 暴露 REST 接口，`playbook/` 为独立文档站点），`src/components/ui` 提供原子化 UI 组件，`src/features/` 按业务域拆分（ai、artifacts、audio、canvas、director、navigation、render），`src/lib/` 存放跨领域基础设施（config、db、determinism、gsap、hooks、layout、motion、queue、storage、stream）。API 层通过 Next.js Route Handlers 调用 features 下的服务模块；数据库由 Drizzle ORM 管理，schema 位于 `src/lib/db/schema.ts`，迁移输出至 `src/lib/db/migrations`。构建时通过 `next.config.ts` 的 `serverExternalPackages` 将 `better-sqlite3`、`ffmpeg-static` 标记为外部依赖以支持原生二进制运行。测试统一使用 Vitest（`vitest.config.ts` 配置 `@` 别名与 `node` 环境），E2E 截图与日志沉淀在 `.playwright-cli/`。
