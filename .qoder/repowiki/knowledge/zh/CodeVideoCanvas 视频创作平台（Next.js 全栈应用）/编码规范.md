- 每个 `src/features/<domain>/` 目录通过 `index.ts` 统一 re-export 公共 API，对外仅暴露聚合入口，内部实现文件按需导入。
- 所有用户输入与配置均使用 Zod schema 进行运行时校验，并在 `*.test.ts` 中配套编写校验用例。
- 测试文件与源码同目录放置，命名约定为 `<file>.test.ts`，由 Vitest 自动发现并运行。
- 路径别名统一使用 `@/` 指向 `src/`，在 `vitest.config.ts` 与 TypeScript 中同步配置。
- Next.js API 路由按资源划分目录（如 `api/artifacts/[id]/route.ts`），服务端逻辑委托给对应 feature 模块的服务函数。
- UI 组件遵循 `component.tsx` + `component.demo.tsx` 成对组织，demo 文件用于 Storybook 或本地预览。
