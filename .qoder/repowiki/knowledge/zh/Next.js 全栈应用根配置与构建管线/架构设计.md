本仓库为单一 Next.js 应用，所有业务域（features/*）、共享库（lib/*）、UI 原语（components/ui）与路由（app/*）由根级配置文件统一约束：
- `next.config.ts` 以 `serverExternalPackages: ['better-sqlite3', 'ffmpeg-static']` 强制原生二进制在 Node runtime 解析，避免 Turbopack 重写平台路径；同时声明全栈模式（非静态导出）。
- `tsconfig.json` 启用 strict + noEmit + bundler 解析，并通过 `@/* → ./src/*` 路径别名打通编译期 import，exclude 掉 `.data`、`docs/video-director` 等生成目录。
- `vitest.config.ts` 将测试环境固定为 node，并复用同一 `@` alias 使单元测试可直引 src 源码。
- `drizzle.config.ts` 锁定 SQLite dialect、schema 入口 `src/lib/db/schema.ts` 与迁移输出 `src/lib/db/migrations`，供所有特征域共享同一数据库实例。
- `eslint.config.mjs` 基于 ESLint flat config 展开 `eslint-config-next/core-web-vitals` 与 `types` 规则，忽略 `.next/out/.data/docs` 及生成的 migrations。
- `postcss.config.mjs` 接入 `@tailwindcss/postcss` 驱动 Tailwind v4 样式管线。
- `package.json` 通过 pnpm overrides 锁定 `typescript-eslint` 8.61.1 与 `better-sqlite3` 12.1.0，并用 `onlyBuiltDependencies` 限定原生包范围，配合 `pnpm@9.15.0` 作为唯一包管理器。
