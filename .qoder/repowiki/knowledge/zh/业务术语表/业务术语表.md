### CodeVideoCanvas
- 定义：项目代号，意为“基于自然语言的代码视频创作工作流程节点平台”，将一段文字稿经语义分镜、节点式画布、逐镜代码视频、音画合成后导出为成片 MP4 的本地优先 AIGC 工具。
- 别名：CVC

### HyperFrames 思想
- 定义：本项目的渲染范式：每镜一份自包含 HTML，通过 `window.__CVC_RENDER__@v1` 暴露 `seek(frame, fps)` 确定性接口，服务端用 Playwright 逐帧 seek 截图到磁盘 PNG 序列，再由 ffmpeg 流式编码为 MP4；同帧永远同画面，支持内容哈希缓存与定向重渲。
- 别名：HyperFrames

### video-director
- 定义：项目参考语料库（位于 `docs/video-director/`），是一套“稿子→高完成度确定性成片”的八阶段方法论原型（44 schema + 22 测试），在本项目中仅作为开发期参照文本，不作为运行时 Skill 或文件依赖；其方法论已移植为本项目原生的 TypeScript prompt/schema/tool。
- 别名：video-director skill

### DirectorSession
- 定义：项目封装的 Director 运行层抽象，对外最小接口为 `{ id, storageKey, run({ prompt, tools }), close() }`，内部组合 Pi `Agent` 与 `JsonlSessionRepo`，负责 Agent 运行、消息事件持久化与恢复；不依赖 `pi-coding-agent`，不加载 Skill/Extension。

### 分镜通道
- 定义：语义拆分完成后程序化 fan-out 出的 N×5 个并行节点通道（脚本/代码/音效/字幕/验收），每通道对应一个分镜，互相解耦，只能通过收敛点交汇；每个通道的“代码生成”节点自带独立预览与独立导出能力，支撑定向重渲。
- 别名：shot lane

### 配方（G01–G50）
- 定义：可复用的时间线动画配方集合，配合 token 注入层实现跨分镜复用；每份配方产出独立的 HyperFrames HTML，seed 由 project/node/shot 派生以保证确定性。
- 别名：recipe

### 确定性红线
- 定义：视频必须是 `f(frame)` 的纯函数——禁止 rAF、墙钟 `Date.now`、无种子随机；任何违规在 HTML 生成 Tool 返回结果之后、进入渲染队列之前由 `lib/determinism` 的 lint 守卫强制拦截，Tool 返回结构化错误让 Agent 自行重试或升级人工介入。
- 别名：确定性

### AppShell
- 定义：最新 canvas.pen 的统一应用壳组件，S1–S6 均以同一个 Sidebar 为首列；页面只切换激活项，不再各自实现导航或顶部品牌栏；响应式/可调宽交互下沉到 AppSidebarShell。

### AppSection
- 定义：应用侧边栏导航区段枚举，当前包括 workbench（工作台）、projects（项目列表）、canvas（画布编辑器）、renderer（分镜渲染器）、export（合成与导出）、settings（设置）。
