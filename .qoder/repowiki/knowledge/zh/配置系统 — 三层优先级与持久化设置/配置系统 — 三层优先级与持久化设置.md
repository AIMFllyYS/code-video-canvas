本项目的配置系统围绕「settings 表 > 环境变量 > 内置默认值」的三层优先级展开，覆盖 StepFun、Gemini 两个 AI 提供商的配置以及 Director 节点路由策略，并通过 Next.js API 路由暴露统一的设置读写接口。

### 1. 使用的框架与工具
- **运行时配置加载**：直接读取 `process.env`，无 dotenv 中间层；通过 `server-only` 标记确保仅在服务端执行。
- **持久化存储**：使用 Drizzle ORM + SQLite（`better-sqlite3`），`settings` 表作为键值对存储用户通过设置页修改的配置。
- **输入校验**：Zod schema（`stepfunSettingsSchema`）在 API 层对 POST 请求体进行校验。
- **路径与环境变量**：`DATA_DIR` 环境变量控制 SQLite 数据库与产物根目录，由 `src/lib/config/paths.ts` 统一解析。

### 2. 核心文件与模块
- `src/features/ai/config.ts` — StepFun 配置的三层解析、读写 settings 表的通用函数（`getSettingValue` / `setSettingValue`）。
- `src/features/ai/gemini-config.ts` — Gemini 配置的同类实现，复用 StepFun 的 settings/env/default 模式。
- `src/features/ai/model-routing.ts` — Director 各节点到 provider 的路由策略，支持按节点类型覆盖默认 provider。
- `src/app/api/settings/route.ts` — 统一的 GET/POST 设置接口，聚合 StepFun/Gemini/Director Routes 的读写。
- `src/lib/db/schema.ts` — `settings` 表结构定义（key/value/timestamp）。
- `src/lib/config/paths.ts` — `DATA_DIR`、`DB_PATH`、`ARTIFACTS_DIR` 等路径常量，受 `DATA_DIR` 环境变量覆盖。
- `.env.example` — 所有可配置环境变量的示例与优先级说明。

### 3. 架构与设计决策
- **三层优先级**：每个字段独立按 `settings 表 → process.env → 内置 DEFAULTS` 解析，空字符串视为未设置并回退到下一层。
- **API Key 特殊处理**：apiKey 不参与 describe 视图（避免泄露），且保存时走独立的 validateKey 门禁。
- **按 Provider 隔离**：StepFun 与 Gemini 各自维护独立的 SETTINGS_KEYS、ENV_KEYS、DEFAULTS 映射，但共享 `getSettingValue`/`setSettingValue` 底层能力。
- **Director 路由可配置**：每个 CanvasNodeType 可通过 `director_provider_<nodeType>` 键覆盖默认 provider，未配置时回退到内置 DEFAULT_PROVIDER。
- **设置页即真相源**：用户在 UI 设置页修改的值写入 SQLite，重启后依然生效；留空则显式回退到 env/default。

### 4. 约定与约束
- **字段命名约定**：
  - Settings 表 key 前缀为 `<provider>_`（如 `stepfun_api_key`、`gemini_base_url`、`director_provider_shot-script`）。
  - 环境变量名大写且带 provider 前缀（如 `STEPFUN_BASE_URL`、`GEMINI_PRIMARY_MODEL`）。
- **空值语义**：空字符串或 undefined 传入 `setSettingValue` 会删除对应行，使该字段回退到 env/default。
- **只读描述接口**：`describeStepfunConfig()` / `describeGeminiConfig()` 返回 `{ value, source }` 视图，source 为 `'settings' | 'env' | 'default'`，用于设置页展示。
- **DATA_DIR 不可通过设置页修改**：当前仅通过环境变量覆盖，API 返回 `storageDir` 供前端显示。
- **Next.js 外部包声明**：`next.config.ts` 中声明 `better-sqlite3`、`ffmpeg-static` 为 serverExternalPackages，确保原生依赖在 Node 运行时解析。
- **测试覆盖优先级矩阵**：`config.test.ts` 明确断言 settings > env > default 的优先级行为及空串回退逻辑。
