## 系统概述
CodeVideoCanvas 采用「settings 表 > 环境变量 > 内置默认值」的三层优先级配置体系，所有运行时配置（StepFun、Gemini 等 AI Provider 的 Key/端点/模型）均通过统一的 resolver 解析，并通过 Next.js API 路由暴露设置页进行动态修改。

## 核心架构与文件
- **路径与环境变量**：`src/lib/config/paths.ts` 提供 `DATA_DIR`、`DB_PATH`、`ARTIFACTS_DIR`，仅依赖 `process.env.DATA_DIR`，默认 `.data` 目录，启动时 `ensureDataDirs()` 幂等创建。
- **StepFun 配置**：`src/features/ai/config.ts` 定义 `getStepfunConfig()` / `describeStepfunConfig()` / `saveStepfunModelSettings()`，字段包括 apiKey、baseUrl、chatModel、ttsModel、asrModel、visionModel。
- **Gemini 配置**：`src/features/ai/gemini-config.ts` 以相同模式实现 apiKey、baseUrl、primaryModel、fastModel 的三层解析。
- **设置 API**：`src/app/api/settings/route.ts` 统一 GET/POST 接口，支持校验 Key、保存配置、返回生效值及来源。
- **数据库 schema**：`src/lib/db/schema.ts` 中 `settings` 表为键值对存储（key/value），是配置的唯一定义源。

## 设计决策与约定
1. **严格优先级**：settings 表（设置页配置）> 环境变量 > 内置默认值。任一来源为空则自动回退下一层，空字符串视为未设置。
2. **Key 单独处理**：apiKey 不参与 resolveField 流程，直接从 settings 或 env 读取，不暴露明文，API 返回掩码形式。
3. **字段级覆盖**：每个配置项独立解析，可单独覆盖某一项而不影响其他项。
4. **服务端隔离**：配置模块使用 `import 'server-only'` 确保仅在服务端执行。
5. **类型安全**：所有配置字段通过 TypeScript 类型约束，settings 表 key 名集中定义在常量对象中。
6. **验证门禁**：保存 Key 前必须通过 `validateKey()` / `validateGeminiKey()` 校验，失败则拒绝更新。
7. **数据目录不可配置**：`DATA_DIR` 仅通过环境变量设置，设置页不暴露修改入口。

## 配置来源说明
- **内置默认值**：定义在各 config.ts 文件的 DEFAULTS 常量中，与 `.env.example` 保持一致。
- **环境变量**：通过 `.env.local` 或 `.env` 文件注入，开发测试阶段可直接使用。
- **运行时设置**：通过设置页 POST `/api/settings` 持久化到 SQLite settings 表，重启后依然生效。
- **Director 路由**：模型路由配置也通过同一机制管理，支持按节点选择 provider。

## 约束与规则
- settings 表中值为空串或未定义时，对应行会被删除，自动回退到 env/默认值。
- 所有配置项的 source 字段明确标注来源（settings/env/default），便于调试和审计。
- DATA_DIR 必须在应用启动前设置，否则默认使用当前工作目录下的 `.data`。
