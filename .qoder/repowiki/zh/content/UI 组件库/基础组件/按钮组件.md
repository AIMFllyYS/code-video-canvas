## 详细组件分析

### 属性接口
- className: string | undefined
  - 作用：透传给根元素，允许外部覆盖或追加样式类名。
- variant: "primary" | "secondary" | "ghost" | "destructive" | "launchCTA"
  - 作用：控制按钮视觉风格。
  - **新增**：launchCTA 专用于启动调用场景，具有独特的视觉强调效果。
  - 默认值：通常为 primary（以实际实现为准）。
- size: "sm" | "md" | "lg"
  - 作用：控制按钮尺寸（高度、内边距、字号等）。
  - 默认值：通常为 md（以实际实现为准）。
- isLoading: boolean
  - 作用：显示加载态（如禁用交互、显示加载指示器）。
- isDisabled: boolean
  - 作用：禁用按钮交互与键盘操作。
- 其他标准 HTML 按钮属性
  - 例如 type、aria-*、data-* 等，通常透传给底层原生按钮元素，保持浏览器兼容性与可访问性。

**更新** variant 类型新增了 "launchCTA" 选项，专门用于启动调用场景，提供更明确的视觉层次。

### 变体与尺寸矩阵
- **新增变体详解**
  - **Primary**：主要操作按钮，具有最强的视觉强调，常用于表单提交、创建等主要操作。
  - **Secondary**：次要操作按钮，中等视觉强调，常用于取消、返回等辅助操作。
  - **LaunchCTA**：启动调用按钮，专为启动流程设计，具有独特的动画效果和视觉反馈。
  - ghost：轻量背景透明，常用于工具栏、辅助操作。
  - destructive：危险操作，常用于删除、清空等。
- 尺寸
  - sm：紧凑空间下的按钮。
  - md：默认尺寸，适用于大多数场景。
  - lg：大尺寸，突出重要操作或在移动端提升点击区域。

**更新** 新增了三种专门设计的按钮变体，每种都针对特定的业务场景进行了优化，提供了更精确的视觉层次和交互反馈。

### 状态说明
- loading
  - 表现：禁用交互、显示加载指示器（若实现包含图标槽位）。
  - 建议：在异步请求期间启用，避免重复提交。
- disabled
  - 表现：不可点击、不可聚焦、视觉上弱化。
  - 建议：在条件不满足时禁用，配合提示文案说明原因。
- **新增状态处理**
  - launchCTA 变体在激活时具有特殊的动画效果和视觉反馈。
  - 所有变体都支持一致的 hover、active、focus 状态处理。

**更新** 新增了对 launchCTA 变体的特殊状态处理，包括激活时的动画效果和视觉反馈。

### 事件处理机制
- onClick
  - 触发时机：用户点击按钮时。
  - 注意事项：在 loading 或 disabled 状态下应阻止默认行为。
  - **增强**：launchCTA 变体在点击时具有额外的动画反馈。
- onKeyDown
  - 触发时机：键盘操作（Enter、Space 等）时。
  - 无障碍要求：确保 Enter/Space 可触发主要动作，符合 WAI-ARIA 规范。
- 其他事件
  - 所有标准 DOM 事件均可透传，便于上层自定义逻辑。

**更新** 增强了事件处理机制，特别是针对新增的 launchCTA 变体添加了特殊的动画反馈。

### 使用示例与最佳实践
以下为常见场景的使用思路与要点（不包含代码内容，仅给出路径参考）：
- **主要操作**
  - 使用 Primary 变体，结合 isLoading 防止重复提交。

- **次要操作**

  - 使用 destructive 变体，明确风险语义，必要时二次确认。
- **工具栏/辅助操作**
  - 使用 ghost 变体，减少视觉干扰。

## 性能考虑
- 最小重渲染
  - 将 isLoading、isDisabled 等布尔值稳定化，避免不必要的重渲染。
- 事件节流
  - 在高频触发的场景中（如搜索框内的"搜索"按钮），对 onClick 做防抖或节流。
- 懒加载与按需引入
  - 若 Button 体积较大，可在需要时再导入，减少首屏资源。
- **新增优化**
  - 新变体的动画效果采用硬件加速，确保流畅的用户体验。
  - 样式计算优化，避免频繁的重新布局。

**更新** 新增了针对新变体的性能优化措施，确保动画效果和样式计算的流畅性。

## 故障排查指南
- 问题：点击无效
  - 检查是否处于 loading 或 disabled 状态。
  - 确认 onClick 是否正确绑定且未提前 return。
- 问题：键盘无法触发
  - 确认使用原生 button 元素，并确保 Enter/Space 未被拦截。
- 问题：样式未生效
  - 检查 className 是否被覆盖，确认主题变量是否正确注入。
  - **新增**：检查新变体的样式是否正确应用。
- 问题：读屏器未正确播报
  - 检查 aria-disabled、aria-busy 等属性是否正确设置。
  - **新增**：确认新变体的 ARIA 标签是否正确配置。
- 问题：动画效果异常
  - **新增**：检查动画库是否正确加载，确认浏览器兼容性。

**更新** 新增了针对新变体和动画效果的故障排查指南。
