# PurpleInk Design Package Manifest

This package contains a synthesized agent handoff plus read-only copies of the five requested source references. The synthesized guide is the entry point; source copies provide provenance and allow the package to be understood independently of the working tree.

## Contents

- `PURPLEINK_DESIGN_SYSTEM_AGENT.md`: consolidated design-system handoff and implementation rules.
- `source-reference/DESIGN.md`: English design specification.
- `source-reference/PURPLEINK_DESIGN_SYSTEM_FEISHU.md`: Chinese production specification.
- `source-reference/PURPLEINK_COLOR_SYSTEM.md`: palette and governance reference.
- `source-reference/colorbox-import.json`: ColorBox candidate-ramp configuration.
- `source-reference/globals.css`: implementation snapshot used for the mapping.
