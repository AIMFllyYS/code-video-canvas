## 1. 产品概述

### 1.1 一句话定位

把一段文字稿，通过"语义分镜 → 节点式画布 → 逐镜代码视频 → 音画合成 → 一键导出"，变成一支高完成度短视频的**本地优先 AIGC 视频创作引擎**。

### 1.2 产品愿景

让"写好一段稿子"和"得到一支专业动态视频"之间只隔一块可视化画布：每个分镜是一个可**独立生成、独立渲染、独立修改**的节点，AI 负责把语义翻译成**确定性**的代码动画。

### 1.3 电梯演讲

面向内容创作者 / 技术布道者 / 教育者：你不需要会 After Effects，也不用手写 Remotion。把稿子丢进来，系统按语义拆分镜、为每个分镜生成 HTML+GSAP 代码视频、配上音效字幕配乐与转场，最后**在你自己的电脑上**渲染导出成片。改一个分镜，只重渲那一个节点。

## 2. 背景与问题

### 2.1 问题陈述

- 程序化视频（Remotion / HyperFrames）质量高、可复现，但门槛极高：要写代码、懂确定性渲染、手工编排。
- 现有 AI 生视频，要么像素生成（不可控、无法精确改），要么模板拼接（僵硬、无语义）。
- `video-director` skill 已把"稿子 → 高完成度确定性成片"沉淀为八阶段流程 + 40+ schema + QA 门禁，但它是**给 Agent 用的方法论**，不是产品。

### 2.2 为什么是现在

- LLM 写 HTML+GSAP 的"一把过"率已足够高；StepFun（阶跃星辰）等国产模型官方兼容 OpenClaw / MCP / Skills 调用。
- 无头 Chromium 逐帧渲染（HyperFrames 思想）成熟，可在个人电脑上跑。

### 2.3 现有方案不足

Remotion 组件耦合、改一处需重编整包；纯像素 AIGC 不可控；模板工具无语义理解。本产品用"语义分镜 + 单镜隔离 + 确定性渲染"同时解决可控性、可迭代性与复用性。

## 3. 目标用户

### 3.1 用户画像

| 画像 | 描述 | 关键诉求 |
|---|---|---|
| P1 技术内容创作者 / 布道者 | 讲技术、做产品演示 | "讲得清"的动态图形，可控可改 |
| P2 教育 / 科普创作者 | 把文章、讲义转解释性视频 | 语义驱动、低门槛 |
| P3 独立创作者 / 小工作室 | 需要可迭代、可复用的程序化产线 | 单镜可改、成片可复现 |

### 3.2 核心痛点

不会写动画代码；改一版成本高；想要"语义驱动"而非"模板套壳"；**没有高配服务器**。

## 4. 目标与非目标

### 4.1 产品目标

- **北极星**：从"一段稿子"到"一支可导出成片"的端到端成功率与迭代效率。
- **Demo 阶段目标**：本地跑通"稿子 → 分镜节点 → 单镜渲染 → 合成导出"最小闭环。

### 4.2 Demo 范围（In Scope）

剧本导入、语义分镜、分镜描述（AI）、分镜节点、单镜 HyperFrames 渲染、定向重渲、基础音效 / 字幕 / 配音、整体配乐 / 转场、渲染导出、StepFun Key 设置、画布编辑、本地存储。

### 4.3 非目标（Out of Scope，Demo 不做）

登录 / 账号 / 多租户、云端 / 远程存储、API 限流与安全加固、协作 / 权限、计费、Electron 打包分发、Monorepo 拆分、分布式渲染农场。

## 5. 用户故事与场景

**Epic A — 语义分镜**
- US-A1：粘贴一段稿子 → 系统按语义拆成有序分镜 → 画布上看到全片结构。

**Epic B — 分镜生产**
- US-B1：点开分镜节点 → AI 为它生成确定性 HTML+GSAP 代码视频 → 节点内预览。
- US-B2：不满意某分镜 → 只改它、只重渲它 → 其它节点不受影响、命中缓存。

**Epic C — 音画**
- US-C1：为分镜添加 / 生成配音与字幕 → 配音成为该镜时间地基。
- US-C2：系统分析全片 → 给出整体配乐与分镜间转场 / 剪辑建议。

**Epic D — 导出**
- US-D1：一键在本机渲染并导出整片 MP4（含字幕、音轨、转场）。

**Epic E — 配置**
- US-E1：在设置页填入自己的 StepFun Key → 校验通过后 AI 功能可用。

## 6. 功能需求

### 6.1 功能全景

画布 = video-director DAG 的可视化投影：**上游**语义 / 风格节点 → **中游**分镜节点（一节点一 HTML 代码视频）→ **下游**音频 / 合成 / 导出节点。

### 6.2 功能清单（优先级 P0 > P1 > P2）

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| F1 | 剧本导入 | 粘贴 / 导入文字稿，可选配音 | P0 |
| F2 | 语义分镜 | 按语义拆分镜，生成 script-units | P0 |
| F3 | 分镜描述 | AI 生成每镜视觉 / 内容合同（shot-plan） | P0 |
| F4 | 分镜节点渲染 | 每镜一份 HTML+GSAP，本机逐帧 seek 渲染 | P0 |
| F5 | 定向重渲 | 改单节点仅重渲该节点（内容哈希缓存） | P0 |
| F6 | 画布编辑 | 增删改分镜节点、连线、排序 | P0 |
| F7 | 项目本地存储 | 画布 / 状态 / 产物本地持久化 | P0 |
| F8 | StepFun Key 设置 | 本地填写与校验 | P0 |
| F9 | 合成导出 | 拼接 + 音轨 + 字幕 → 成片 MP4 | P0 |
| F10 | 字幕 | 由稿 / 配音对齐生成字幕 | P1 |
| F11 | 配音 | 导入 / 生成配音，作为时间地基 | P1 |
| F12 | 整体配乐 BGM | 全片分析给出配乐 | P1 |
| F13 | 转场 / 剪辑 | 分镜间基础转场与链接剪辑 | P1 |
| F14 | 音效 SFX | 分镜级音效 | P2 |

### 6.3 关键交互流程

导入稿子 → 语义分镜生成节点 → 逐镜 AI 生成并预览 → 局部改单镜（定向重渲）→ 加音频 / 字幕 → 全片配乐 / 转场 → 合成 → 导出 MP4。

## 7. 非功能需求

- **确定性**：视频是 `f(frame)`，禁 rAF / 墙钟 / 无种子随机；同帧同画面。
- **性能**：单镜渲染秒级迭代；首轮全片可数分钟；有界并发 + 内容哈希缓存。
- **本地优先 / 无服务器**：全部本机运行；AI 用用户自带 Key 直连 StepFun。
- **可恢复**：作业状态持久化（SQLite），崩溃可续渲。
- **隐私**：Key 不进前端 bundle；数据不出本机。
- **可演进**：领域逻辑集中于 `features/*`、`lib/*`，未来抽包 / 上云 / Electron 低成本。

## 8. 产品流程 / Pipeline（八阶段映射）

`INGEST`（分镜 + 音频地基）→ `DIRECT`（风格圣经）→ `SHOT-SPEC`（每镜合同）→ `FABRICATE`（逐镜 AI 生成 + 本机渲染）→ `ASSEMBLE`（配乐 + 转场 + 拼接）→ `FINALIZE`（QA 抽帧 + 终渲）。每阶段映射到画布节点与后台作业队列。

## 9. 里程碑与迭代

| 阶段 | 范围 |
|---|---|
| **Phase 0（本 Demo）** | 最小闭环：导入 → 分镜 → 单镜渲染 → 合成导出，全本地 |
| Phase 1 | 音频 / 字幕 / 配乐 / 转场完善 + QA 抽帧 |
| Phase 2 | Electron 桌面打包分发（用户自带 Key、代码签名） |
| Phase 3 | 规模化：Monorepo / adapters / 可选服务器或云版 |

## 10. 验收标准（Demo DoD）

- 能导入稿子并生成多个分镜节点；
- 每个分镜节点能独立生成 HTML 并在本机渲染出片段；
- 改单个分镜只重渲该节点、命中缓存；
- 能合成导出一支带字幕 / 音频的 MP4；
- 全流程本机、无需服务器；StepFun Key 本地配置即生效；
- `pnpm lint` / `pnpm tsc --noEmit` / `pnpm build` 通过；关键路径有测试。

## 11. 度量指标

端到端成片成功率、单镜迭代耗时、首轮全片渲染耗时、单镜重渲缓存命中率、AI 生成一把过率。

## 12. 风险与依赖

| 风险 | 缓解 |
|---|---|
| 跨机字体 / GPU 决定性差异 | 打包字体、QA 基准机、复杂镜预算 |
| 本机渲染性能上限 | 内容哈希缓存、有界并发、复杂度预算 |
| LLM 生成不确定 / 不合规 | schema 校验 + 确定性 lint + QA 门禁 |
| 外部依赖 | Playwright/Chromium、ffmpeg-static、StepFun 可用性 |

## 13. 未来规划

Electron 分发与自动更新、Monorepo 拆分、服务器 / 云版（走 adapters）、多人协作、模型可插拔（StepFun 之外）。

## 14. 术语表

**分镜 / shot**：一个语义单元的镜头。**节点**：画布上对应一个分镜或一个流水线阶段。**确定性渲染**：同帧永远同画面。**HyperFrames 思想**：单 HTML + `data-*` 时序 + 逐帧 seek 截图 → FFmpeg。**八阶段**：video-director 的编译流程。**配方（G01–G50）**：可复用的时间线动画配方。**StepFun**：阶跃星辰，OpenAI 兼容的 LLM 提供方。
