# Issues 11–13 and Gemini Routing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 issue 11–13 的完整施工，并新增可按画布节点选择的 Gemini/StepFun 推理路由，最后通过真实 API 与浏览器端到端验收。

**Architecture:** 项目级 autopilot 在服务端消费既有 DAG 边；audio/render 域以独立 side-effect 端口接入 StepFun TTS/ASR 与结构化 Vision QA；Director runner 对门禁错误执行同会话有界反馈；AI 配置层新增 Gemini resolver 和节点 route，Pi session 只消费服务端可信 route。所有字节继续经 `StorageAdapter`，所有 Key 继续只存在于 settings 或被忽略的本地环境文件。

**Tech Stack:** Next.js 16 App Router、TypeScript strict、Drizzle/SQLite、Vitest、Pi Agent/pi-ai、OpenAI-compatible SDK、StepFun Audio API、Gemini API、Playwright。
