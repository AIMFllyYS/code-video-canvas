## U1.8 暴露并修正的规格与架构缺口

1. INGEST/FABRICATE 原先缺少“模型输出到应用副作用”的阶段提交协议。现统一为
   类型化归一、artifact 门禁、应用副作用提交、节点 success；INGEST 不再让模型
   猜测音频数据。
2. `ffmpeg-static` 未保持 Next server external，生产 bundle 会把 Windows 二进制
   路径改写为 `/ROOT`。现已加入外部包边界与回归测试。
3. render cache key 与最终实体 `contentHash` 曾混用。现缓存寻址与 MP4 SHA-256
   分离，数据库保存实体哈希。
4. 旧 UI 文档残留独立 TopNav 心智模型，与最新 Pencil 的全局 Sidebar 冲突。
   AGENTS、Harness、平台架构、UI 交接和设计系统清单已同步为唯一 AppShell 规则。
5. S4 原实现缺少 Pencil 中的代码列；S5 原实现使用固定片段和 QA 常量。两处均已
   改为真实读模型投影。
6. 走查期间浏览器出现一次 `favicon.ico` 404；它不影响业务链路，未发现其他
   console error。

## 受控偏差与未执行项

- 为遵守“每 Track 只做一次真实 AI 调用”的验收预算，本轮只真实调用了 INGEST。
  当前 Demo 尚无自动串行执行 DIRECT→SHOT-SPEC→FABRICATE 的 UI 编排，因此 S001
  使用仓库已有的 `deterministic-shot.html` fixture 写入隔离 E2E 数据，专门验证
  S4→Render→MP4 链路。它不是第二次模型生成，也没有冒充真实 FABRICATE 结果。
- S002/S003 与音频节点按预期仍未完成，所以没有强行执行合并导出；U1.8 要求验证的
  正是“未完成时禁止导出”门禁。
- Audio 的真实 TTS/ASR/SFX/BGM 按 A1.1 规格属于 P1，Demo 使用结构化 placeholder，
  不视为跳过任务。
- 没有跳过 F/C/D/R/A/P/U 的任何 Task；没有进行主观视觉质量评价。
- 工作区已有的 `docs/designs/canvas.pen` 修改保持未提交，未覆盖 Pencil 编辑器状态。
